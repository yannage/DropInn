# DropInn continuity catalog

This is an authoring reference for the existing original universe, not a new adventure or a global persistent-world system. Identifiers below are canonical reference names; existing target IDs and published adventure versions remain unchanged.

| Reference ID | Existing character/place | Established role | Runtime source |
| --- | --- | --- | --- |

| `npc.gloamfang` | Gloamfang | Guardian connected to the broken ward and chapel bell | Briar Glen, chapel scene |

| `place.teacup` | The Teacup | Runaway postal airship and its rescue | The Last Flight of the Teacup v1 |

Before reusing a character, read the authored source and record the version. An individual table's rescue, route cost, or failed attempt is local to that visit; a later published episode establishes its own explicit starting situation. Do not assume every player has completed an earlier adventure.

For each future addition record: reference ID, authored source, name, role/motivation supported by that source, relationships, art keys, allowed variation, and immutable facts. Expand this catalog through story review rather than generated dialogue. New story packets should list reused references, what a newcomer must know, and what the episode changes. Runtime canon/version resolution is a later content feature, not inferred from this document.
