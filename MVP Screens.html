Engineering handoff — surface area

The minimum API the front-end needs to drive every screen above. All in-memory in V1; localStorage shape mirrors this 1:1.

Lobby

listCampaigns(filters?) → Campaign[]
enterRoom(id) → emits "previously-on" event
wakeRoom(id) → status: sleeping → active

Scene

getCurrentScene(roomId) → Scene
commitAction(actionId, targetId?)
spotlightMove(text) → mapped narrative
resolveTurn() → rolls + outcome line

NPC

NPC.traits: { race, gender,
  demeanor, appearance, build,
  motivation, quirk }
NPC.dialogue_topics[] → topic + said
+ optional unlock requirement

Player & persistence

getPlayer() → Player
leaveRoom(id) → narrated exit
grantReward(xp, item?)
all writes persist to localStorage

Notifications

subscribeEvents(cb)
event.kind: "join" | "leave" |
  "item_drop" | "scene_complete" |
  "world_tick"

· npc_generator(theme) → NPC[]
· llm_narrate(scene, outcome)
· ws_presence(roomId)
· filter_query in lobby
